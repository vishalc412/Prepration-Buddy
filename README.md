# Prepration Buddy (OFFline and AI)

A self-contained **30-day, four-hour-per-day interview guide**: 120 active hours, from Python/Java foundations through the 50 client questions you supplied. Open `index.html` in a browser; no server, account, API key or model is required.

Hands-on coding remains **Python and Java only**. Other modernization targets use Python-built adapters or optional AI-assisted plugins, with build and behavior evidence.

1. Start at **Home**, select a course chapter, then open **Learn**. Each day has six steps: recall 20 minutes, mechanisms 50, worked example 30, build/test 75, design/defend 40, review 25. Total 240 active minutes; add breaks separately.
2. **Study** makes bundled answers available. **Challenge** asks for an attempt before revealing that question’s suggested answer. Saved attempts remain available. Library/search are deliberate review tools.
3. Open **Train for client interview** for all 50 original questions. Each has intuition, mechanism, concrete example, suggested answer, three hints, pitfalls, two answered follow-ups and two explained fixed checks. Practice one question through Understand → Answer → Drill & defend. Search topics, use the revisit queue or run the ten-question recall circuit.
4. Download the day’s reference files and run them locally. Browser code editors save drafts; they do not execute Python or Java. The 16 new advanced labs use Python’s standard library and deterministic fixtures. Earlier framework/ML labs need their stated packages installed.
5. Record actual evidence, compare your explanation and revisit gaps. Fixed quizzes grade only their stated checks. Essays, code quality and personal readiness remain self-assessed or reviewed independently.
6. Export progress backups regularly. The same `principal-ai-studio-v1` key and version 1 format preserve original answers, code, Java drafts and evidence. Legacy six-hour editions migrate to four hours once; new days 15–30 survive reload and import. Copying HTML alone does not copy browser progress.
